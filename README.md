# Sophisticated Storage (Unofficial Fabric Continuation)

## Original mod, license and credits

This repository is a continuation of the **unofficial Fabric port** of **Sophisticated Storage**, forked from the
GPL-licensed branch maintained by **Salandora**.

**The original mod has since been relicensed to ARR (All Rights Reserved).** This project is therefore
developed from the earlier revision that was still published under the **GNU General Public License
v3.0**, and it is released under the **same license** — see [LICENSE](LICENSE).
It **does not contain, and will never contain, any new content from the original mod**: every change
made here is our own work on top of that GPL revision. The original copyright notices and the license
text are kept unchanged.

* **Sophisticated Storage** — original mod and original author: **P3pp3rF1y**.
* **Sophisticated Storage (unofficial Fabric port)** — **Salandora**, whose GPL v3 branch this continuation is
  based on.
* **This continuation** — Huziyang520.

Our thanks to P3pp3rF1y for creating the mod and to Salandora for porting it to Fabric, and to both of
them for releasing that work under a license which allows it to be continued. As the original authors
do, we also thank the Minecraft modding community — the mapping and modloader teams, the authors of the
mods we integrate with, and everyone who reports bugs or suggests improvements — for making work like
this possible.

## Requirements

* Minecraft (Fabric)
* [Fabric API](https://modrinth.com/mod/fabric-api)
* [Sophisticated Core](https://github.com/Huziyang520/Sophisticated-Core-Unofficial-Fabric-Continuation) — required
* [Cloth Config API](https://modrinth.com/mod/cloth-config) — required, it provides the in-game configuration screen
* [Mod Menu](https://modrinth.com/mod/modmenu) — optional, adds the config button to the mod list
* Optional integrations: JEI, REI, Jade, Litematica, Chipped, Tom's Simple Storage, Crafting Tweaks, AudioPlayer, Sodium
