# Sophisticated Storage (Unofficial Fabric Continuation)

Fancy and functional storage containers: upgradable chests, barrels, limited barrels and shulker boxes.

## What it does

Fancy and functional storage containers. Every container is upgradable and keeps its
contents and its settings when you upgrade it:

* **Chests, barrels, limited barrels and shulker boxes** in wood, copper, iron, gold, diamond and
  netherite tiers — the tier decides the number of slots;
* **Upgrades** for every container: pickup, magnet, filter, void, feeding, compacting, cooking,
  crafting, stonecutter, jukebox, stack size, tank, pump, experience pump, compression, hopper,
  infinity;
* **Storage controller** for multi-block setups, plus storage input / output / link blocks for
  piping items in and out;
* **Decoration table and paintbrush**: apply materials, main colour and accent colour to containers,
  in the block or in the world;
* **Packing tape** to pack containers so they keep their contents, and tier upgrades that convert
  vanilla chests, barrels and shulker boxes into their sophisticated versions.

## Requirements

* Minecraft (Fabric)
* [Fabric API](https://modrinth.com/mod/fabric-api)
* [Sophisticated Core](https://github.com/Huziyang520/Sophisticated-Core-Unofficial-Fabric-Continuation) — required
* [Cloth Config API](https://modrinth.com/mod/cloth-config) — required, it provides the in-game
  configuration screen
* [Mod Menu](https://modrinth.com/mod/modmenu) — optional, adds the config button to the mod list
* Optional integrations: JEI, REI, Jade, Litematica, Chipped, Tom's Simple Storage, Crafting Tweaks,
  AudioPlayer, Sodium

# Sophisticated Storage（非官方 Fabric 移植续）

精致而实用的存储容器：可升级的箱子、桶、限量桶与潜影盒。

## 功能简介

精致而实用的存储容器。每个容器都可升级，且升级时保留内容物与设置：

* **箱子、桶、限量桶、潜影盒** 各有木、铜、铁、金、钻石、下界合金储层，储层决定槽位数量；
* 齐全的**升级**：拾取、磁吸、过滤、丢弃、喂食、压缩、烹饪、工作台、切石机、唱片机、堆叠、
  储罐、泵、经验泵、压缩、漏斗、无限；
* **存储控制器** 组织多方块，另有输入 / 输出 / 链接方块用于与管道互通；
* **装饰台与刷子**：为方块内或世界中的容器施加材料、主色与副色；
* **打包胶带** 让容器连同内容物一起搬运；储层升级可把原版箱子、桶、潜影盒转成精妙版本。
